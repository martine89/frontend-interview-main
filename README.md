I think I spent roughly around 16 hours on this assignment, mostly because there were some new things for me to learn and I wanted to take the time to look into them. I also wanted to try to get the dropdown component as "pixel perfect" to the design as possible while still trying to stick to the overall concepts behind shadcn/ui.

I had one open question regarding the "select all" functionality while working on this: Usually I would assume that when a user presses "select all" (since we are paginating this list), we would fetch all available options before doing another purchases query. But since having all products filters ticked would mean the same thing as having no filters ticked, I assumed that for this example we only want select all to mean "all currently loaded filters". In a real world case I would go back to rediscuss the intended outcome, but for this example I just made an assumption.

Due to the nature of the data returned by the purchases api I felt an actual list more fitting than the outlined design of the page on the figma file.

For the Dropdown data, I feel like for the scope of this assignment it is fine to go with the loading spinner while simply loading new data on scroll, but in a real world project I would probably look into those APIs since with their random delays it makes it feel a bit "slow". Other improvements would possibly be to fetch more initial data and start loading more data in at an earlier stage, so that in most cases users won't ever really see that spinner most of the time.
